ACMSSYS.DEVELOPER — GITHUB + DOMÍNIO PRÓPRIO

O pacote já está estruturado para funcionar primeiro no GitHub Pages e depois em domínio próprio.

ARQUIVOS:
- index.html
- cadastro.html
- CNAME
- robots.txt
- sitemap.xml

GOOGLE APPS SCRIPT:
A URL fornecida por você já está configurada no cadastro.html.

WHATSAPP:
Não há redirecionamento automático para WhatsApp. O número é apenas armazenado como lead.

PUBLICAÇÃO INICIAL NO GITHUB:
1. Crie um repositório público.
2. Envie todos os arquivos para a raiz.
3. Settings > Pages.
4. Deploy from a branch.
5. Branch main / root.
6. Save.

QUANDO TIVER SEU DOMÍNIO:
1. Edite o arquivo CNAME e troque:
   SEU-DOMINIO-AQUI.com
   pelo seu domínio real.
2. Edite as URLs de canonical, robots.txt e sitemap.xml para o domínio real.
3. No GitHub: Settings > Pages > Custom domain.
4. Informe seu domínio.
5. No painel da empresa onde comprou o domínio, configure o DNS conforme os registros que o GitHub Pages indicar.
6. Aguarde a propagação e ative HTTPS.

IMPORTANTE:
Você NÃO precisa mudar a URL do Google Apps Script quando trocar do endereço do GitHub para seu domínio. O formulário continuará apontando para o mesmo Apps Script.
